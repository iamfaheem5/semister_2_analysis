## Practice Questions (Subtopic-specific)

**P-New-1. [3 marks] [Easy]**
Define a program and list the steps involved in program development (problem definition → algorithm → flowchart → coding → compilation → testing → documentation → maintenance). For each step give one concrete artifact (e.g., flowchart, source file `.c`, executable).

**P-New-2. [4 marks] [Medium]**
What is structured programming? List its three basic control structures (sequence, selection, iteration) and four advantages over unstructured programming (readability, maintainability, reusability, easier debugging). Illustrate with a small C snippet that uses `if-else` and `while` in a structured way vs a `goto`-heavy unstructured equivalent — explain why the structured version is preferred.

**P-New-3. [3 marks] [Medium]**
Distinguish between syntax error, logical error and runtime error with one C example for each. State at which stage each is detected (compile-time vs run-time) and whether the compiler reports it. Example to include: missing `;` (syntax), `if(a=5)` vs `if(a==5)` (logical), division by zero `10/0` (runtime).
