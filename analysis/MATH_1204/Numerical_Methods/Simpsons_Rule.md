## Practice Questions (Subtopic-specific)

**P3. [4 marks] [Easy]**
Use Simpson's rule with 8 strips to estimate $$\int_0^{\pi}\sin x\,dx$$. Compare with exact value $$2$$ and compute error. Why does Simpson give high accuracy for $$\sin x$$?

**P1-part. [3 marks] [Easy]**
State Simpson's 1/3 rule with graph showing parabolic approximation vs trapezoidal. Write formula for $$n$$ even strips (even $$n$$): $$\int_{x_0}^{x_n}f(x)dx \approx \frac{h}{3}[f_0+f_n+4\sum f_{\text{odd}}+2\sum f_{\text{even}}]$$.

**P-new. [5 marks] [Medium]**
Apply Simpson's 8-strip to $$\int_0^{\pi}\sin x\,dx$$ with $$h=\pi/8$$. Compute table $$x_i, \sin x_i$$ and sum. Show error $$<10^{-3}$$. Also state Simpson's 3/8 rule: $$\frac{3h}{8}[f_0+f_n+3\sum_{3\nmid i}+2\sum_{3\mid i}]$$.
