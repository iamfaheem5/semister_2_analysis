**P10. [7 marks] [Hard]**
(a) Define fundamental mode and pulse mode in asynchronous sequential circuits. (b) Define single-input-change (SIC) hazard free condition and explain static-1 hazard with K-map example. (c) Differentiate Mealy vs Moore machines with state diagrams and output tables (e.g., sequence detector 101) — show why Moore output depends only on state while Mealy depends on state+input.

**P-newAdv2. [4 marks] [Medium]**
Give K-map for $F(A,B,C)= \Sigma m(0,2,5,7)$ showing static-1 hazard when $B$ changes with $A=C=1$. Add redundant prime implicant to eliminate hazard and explain SIC vs MIC hazards. Define fundamental mode constraint for asynchronous circuit.

**P-newAdv3. [3 marks] [Easy]**
Differentiate Mealy and Moore models w.r.t. (i) output function $o=f(s,i)$ vs $o=f(s)$, (ii) number of states for same function, (iii) timing of output glitches. Draw Mealy and Moore state diagrams for sequence detector $101$ (overlap allowed) and compare state count.
